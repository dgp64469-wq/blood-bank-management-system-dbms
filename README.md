# blood-bank-management-system-dbms
Blood is one of the most critical resources in the healthcare sector. Every day, hospitals require blood for surgeries, accident victims, maternity cases, and patients suffering from serious diseases. Managing blood donations, storage, and distribution manually can lead to errors, delays, and even life-threatening situations. Therefore, an efficient and reliable Blood Bank Management System (BBMS) is essential.

**TECHNOLOGIES USED:**
1.Relational Database Management System (RDBMS)
2.Structured Query Language (SQL)
3.Entity Relationship (ER) Model
4.Database Constraints
5.Data Security and Access Control
6.Backup and Recovery Mechanism

**MODULES USED:**
1.Donor Management Module
2.Blood Collection Module
3.Blood Inventory Management Module
4.Recipient Management Module
5.Blood Request Module
6.Report Generation Module
